# ToDo Application

A modern Android application for managing tasks, built with Kotlin and Jetpack Compose.

## Features

- Manage daily tasks effectively.
- Clean and modern UI using Material 3.
- Local data persistence using Room Database.
- Network operations using Retrofit.
- Background services support.

## Tech Stack

- **Language**: Kotlin
- **UI Toolkit**: [Jetpack Compose](https://developer.android.com/jetpack/compose)
- **Dependency Injection**: [Hilt](https://dagger.dev/hilt/)
- **Network**: [Retrofit](https://square.github.io/retrofit/) with Gson
- **Database**: [Room](https://developer.android.com/training/data-storage/room)
- **Asynchronous Programming**: Coroutines & Flow
- **Architecture**: MVVM (Model-View-ViewModel)

## Setup

1.  Clone the repository.
2.  Open the project in Android Studio.
3.  Sync Gradle files.
4.  Run the application on an emulator or physical device.

## Project Structure

- `ui`: Contains UI components and screens.
- `data`: Contains repository implementations, data sources, and models.
- `di`: Dependency injection modules.
- `service`: Android Services implementation.
- `theme`: Theme and typography definitions.
- `DailyProgram`: Contains algorithmic solutions/practice.
